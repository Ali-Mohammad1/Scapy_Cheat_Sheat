# Scapy Cheat Sheet

A comprehensive Python cheat sheet for [Scapy](https://scapy.net/) — the powerful interactive packet manipulation library.

## What's Inside

- **IP** — packet structure, fragment flags, and construction
- **TCP** — flags, options, and segment building
- **UDP** — datagram creation and options
- **ICMP** — types, codes, and echo requests
- **Ethernet** — frame structure and Layer 2 operations
- **ARP** — field explanations, operations, and request/reply frames
- **Send/Receive** — Layer 2 vs Layer 3 functions
